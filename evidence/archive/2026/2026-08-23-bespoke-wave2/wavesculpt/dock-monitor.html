MONITOR — controls hidden, picture resizable

wavesculpt sources · hybrid✕
⚠ THE MONITOR KEYS ARE RUTTETRA’S, NOT THE CARD’S — and copying the card’s would be the bug. The legacy card’s grip writes data.width / data.height (WavesculptCard.svelte:2872-2873) and those size the whole card element at all times, controls visible. Ruttetra’s monitor box uses resizedWidth / resizedHeight, defined as “the size while the controls are hidden”, and clears them when monitor mode turns off. Reusing the card’s keys would make one number mean two things and would resize the legacy card when a player left monitor mode. FaceMonitor is “a record with one REQUIRED field, so tsc refuses the bare monitor: true form” — that field is where this argument goes. spec.md §7.3, MUST-VERIFY §10.4.
⚠ MONITOR AND SCREEN BOTH KEEP RENDERING — and here that is stronger than a preference. This module’s renderer feeds video_out through installWavesculptFrameDrawer, so stopping it would not merely freeze a preview: it would black out an output other modules are consuming. MEASURED with no card mounted: nonBlack 0/3072 px, maxLuma 0, ONE distinct frame signature across 42 rAF frames. Skip the BLIT to the presentation canvas; never skip the render.
