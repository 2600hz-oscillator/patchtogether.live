Two rows alias to the same value, and one of them is invisible. Shown at octave = 5. The write is Math.min(5, EDIT_ROWS - 1 - row) (KriaCard.svelte:162) so rows 0 and 1 both produce 5; the paint is EDIT_ROWS - 1 - row <= oct (:185) which for oct = 5 lights rows 1..6. Clicking row 0 changes the value and shows nothing at all — a control that responds and never reflects its own state. State 4 of the spec's matrix is its regression test, and it must fail on today's code before it passes on the fix.

one click rewrites the whole pattern

The clone is correct and deliberate (never reassign a live Y type at two paths) — do not undo it. The granularity of the write is the problem: two collaborators editing different tracks of one pattern overwrite each other.
