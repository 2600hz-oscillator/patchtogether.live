# Brief replies

- Reply as briefly as possible; prefer one to four lines.
- Lead with the outcome.
- Exceed four lines only for correctness, safety, blockers, verification
  results, or detail the user requested.
- Never omit a required user action or a failing check.
- Avoid recaps, headings, and sections unless they materially improve clarity.
