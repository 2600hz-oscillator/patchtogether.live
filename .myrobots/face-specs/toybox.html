§1 — WHAT THE MODULE IS FOR

The verb is COMPOSE. Four layers, each its own FBO, of kind gen / frag / obj / image / video / off: shader bank content with per-content float params, matcap-shaded OBJ meshes, synced images, and video from a patched feed (inA/inB), a local file, or the camera. An editable combine GRAPH (Phase 4, toybox-combine-graph.ts) reduces them: one SOURCE node per layer, user-added OP nodes from a 17-kind roster — fade lumakey chromakey map over tile mirror displace bitbend biocells feedback exquisite framedelay channeldesync flowsmear dreammelt datamosh (OP_KINDS) — wired by click-to-patch bezier cables into one OUT sink; the engine topo-sorts and evaluates, a disconnected OUT renders black, cycles are refused at edit AND eval time. Six modsignal inputs are ROUTED: each addressed to a layer/op-node param (targets use the graph’s unique display names — “L1”, “LUMA 1”, “DSYNC 2”) with a bipolar SCALE attenuverter + OFFSET and an always-on inline scope. A preset store (bundled + saved-★) captures the whole console; RANDOM rolls a new patch honouring per-layer and per-node LOCKS (#1576 ws3) with REVERT back to the pre-roll patch. Persistence: node.data.layers/.combine/.cvRoutes/.combineView (+ image bytes) ride the Y.Doc; the factory reads the live node each frame.

§5.1 Width — earned, and re-measured, not inherited

The screen + the widest tab (COMBINE GRAPH at a usable editing width) is the earner. The legacy card’s 900 px is the RACK-GRID rounding of a 3-column layout (#759) — the face is a single-column stack (screen → band → tab), so its natural max-content is set by the graph canvas and should land well under 900. Internal overflow:auto where a tab outgrows it (scroll-inside-component, never a plate clamp). Expect zero FACE_WIDTH_EXEMPTIONS entries; M7 measures the stack.

§6.2.1 where the layer strip lives — the argument

Persistent band under the screen, not a fourth tab and not inside the graph tab. Three reasons. (1) Every tab REFERENCES layers but none OWNS them: the graph’s L1–L4 source nodes emit what the layer band configures; the CV tab’s targets address layers and their params; presets capture and lock them. Putting the strip inside any one tab makes the other two dangle references to something off-screen. (2) Parity with the card as the owner asked (“generally keep what we have”): today the layer editor is always visible in the left column while COMBINE and CV/MOD are the two collapsible sections — the tab rail is those two collapses plus presets, restyled; the always-visible part stays always visible. (3) The workflow is layer-first (pick a kind, give it content, THEN wire and modulate) — the band is the module’s spine and the first thing a fresh node needs (“LAYER 1 is empty — pick a KIND above” must not hide behind a tab).

the tab rail is BODY-INTERNAL chrome — state the arithmetic it does NOT invokeThe shell’s dock tab rail is for param BANDS and is gated by DOCK_TAB_MIN_BANDS (7) via dockTabPlan; this face has ZERO bands, so that machinery is untouched. These three tabs are module-owned markup inside fullViewBody — adopt the shell rail’s look (type, spacing, active accent) for the owner’s “new look&feel”, but no shell tab model is imported and no lint reads them. The VRT baseline + toybox-face-model.test.ts are what pin the rail’s existence and default tab.

§6.5 The media-controller tax — what toybox actually pays (unchanged from rev 1, owner design does not touch it)

the one precondition — #1589, closed for the shell world

The discriminator (“is the thing the body needs to show and drive IN THE GRAPH?”) splits toybox’s media three ways: image bytes YES (Y.Doc — no tax); video-file elements and camera tracks NO (browser-local resources named by graph state). Today the CARD owns them with retry timers — so the LRU-evict/collapse unmount kills live layers, the exact #1589 P0, mitigated but not closed. The face PR ports ownership to a node-keyed registry (node-extras-registry / node-video-source-registry family — the repo ships the pattern and its behavioural proof, extras-producer-lifetime.spec.ts): elements and tracks live for the NODE, swept with the graph, the body adopts-and-reads. Export reads the registry’s truth, closing the “Exported … zero video bytes” lie a second way. This is the entire content of needs-media-controller for toybox — a tax already invented twice (cameraInput’s headless host, audioIn’s #1590 registry); toybox takes the registry form because its media is per-LAYER, not per-card.
