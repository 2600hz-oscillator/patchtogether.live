The empty state is a real state, and it must be negative-controlled. The module's shader fills a dark teal when no image is loaded — vec4(0.02, 0.06, 0.08, 1.0) at picturebox.ts:78, chosen so an empty card reads "alive but empty" rather than "broken". MUST-VERIFY M2 asserts both directions: non-black for a loaded node, and that exact idle colour for an empty one — because "black" and "never looked" are indistinguishable from one reading.

why the picture outranks the knob

Owner ruling #1785, recorded at module-shell-model.ts:202-214: "for a video module the picture IS the module's identity in a rack, so it OUTRANKS ranked controls."

So at the tightest lane tiers the Gain fader may be evicted and the picture kept. That is correct here and needs no override — a picturebox you cannot see is not a picturebox.

glyph: 'none' is mandatory, not tasteful

picturebox has exactly one output and it is { id: 'out', type: 'image' }. primaryAudioOutPortId matches type === 'audio' exactly (shell-glyph-live.ts:111-113), so it returns null and every glyph literal except 'none' resolves to {kind:'static'}.

module-face-lint.test.ts:271-290 reddens a dead glyph unconditionally — no exemption list, no count.
