And the state lives on node.data under the fleet-standard previewCollapsed key, reused verbatim so racks saved before the promotion do not silently re-open, and never in component $state (the #1531 / #1574 / #1583 unmount class). On a seven-tab face, persisting across tab switches is the whole point.
twotracks is on the "yes" side of the SCREEN ruling, and audioOut and kria are not. dockscope / spectrograph / samsloop refuse a toggle because the picture IS the module. Here the picture is a preview beside a large control set: with it collapsed you still have transport, rate, echoes, EQ, filter and the mix — a complete, usable tape machine. On the wave's tallest face that reclaimed space is worth real screen. ⚠ And no gate sees the switch — video-face-screen-source.test.ts sweeps listVideoModuleDefs() ∩ STRICT_FACES and this is an audio def, so deleting it tomorrow goes green. It is asserted at SOURCE instead, with an ORDER assertion that the collapse skips the PAINT and never the peak read.

the FILTER MODE control is a downgrade the face fixes

The card exposes filterMode_a as a button that increments modulo 4 (TwotracksCard.svelte:257). To reach mode 1 from mode 3 you press it twice and watch what happens. The four modes have no names anywhere the user can see.

The names exist in prose only: twotracks.ts:317 builds "off / low-pass / high-pass / band-pass", and defaultValue: 0 means the filter ships OFF — which is what the segmented control above shows.

⚠ Two records of that roster already disagree. The file header at :18-19 calls it an "HP/LP/BP filter" — three modes, wrong order, no off. Neither prose record is the source, which is exactly how they drifted.

On the face it is a segmented control over a declared roster — one press, direct addressing, mode names visible. ⚠ The def declares no options today (measured: zero occurrences in twotracks.ts), so adding them is part of this PR, and the cell imports the exported symbol rather than re-typing four strings.

⚠ And note what that changes: an options roster makes the shell render the param as segmented automatically — no paramCells declaration — and it makes the option NAMES paintable, which is the one derived-text shape the ruling permits (a name disambiguates otherwise-identical positions; a number restates the dial).

THE LANE PICTURE IS REFUSED, AND NOTHING STOPS AN AUTHOR FROM CHOOSING OTHERWISE. out_l is type: 'audio', so glyphBinding short-circuits to { kind: 'live-audio', portId: 'out_l' }. The binding is LIVE, the dead-glyph clause is green, and nothing reddens — scope's trap class. Unlike scope's, the trace here would not be a lie; it is refused because a stopped tape, an empty tape and a monitored silence are the same flat picture, and the thing a player wants at a glance — is there tape, where is the playhead — is in none of them. twotracks-face-model.test.ts asserts both halves as a permanent negative leg, so a future author who adds a literal fails a test rather than merely disagreeing with a document.
