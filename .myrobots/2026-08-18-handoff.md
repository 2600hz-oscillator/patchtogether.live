## Things that cost time — do not rediscover these

**`gh pr checks` can report the PREVIOUS run's results** before a new workflow
registers. Poll `commits/<sha>/check-runs` for an exact SHA instead. An agent lost
time to a monitor that also had its SHA hardcoded.

**Report CI state on the head SHA, never the local suite.** Local green is not
evidence about CI — it is the claim CI exists to test. A spec passed 45× locally
and failed twice on CI the same hour.

**Local headless is ALREADY SwiftShader** (`playwright.config.ts`, verified), so
`E2E_SWIFTSHADER=1` changes nothing unless you run headed. And **every CI shard
gets its own dedicated VM** — there is no cross-shard contention to blame. The
real delta is a 2-core CI VM against a dev machine. Both of these were stated
wrongly to agents during this session and cost them work.

**Three VRT watchers polling at 45 s drained the shared `gh` quota to 0/5000.**
`task vrt:watch` now exists (~6 calls scoped / ~18 full). Poll in minutes. ⚠ An
exhausted quota returns 403, which reads as "no data", which reads as "no
failures" — treat a failed call as COULD NOT LOOK, never as a clean result.

**Generated-file merge conflicts: take main AND re-run the accept task.** Taking
main alone silently dropped #1849's content; the regeneration moved 49/50 lines.
The second half of that rule is the load-bearing one.

**`git checkout origin/main -- <paths>` silently clobbers uncommitted work.** An
agent lost two fixes that way. Commit before measuring.

## The pattern worth carrying forward

Nearly every real defect found today was **green, not red** — and every correct
diagnosis came from a measurement while every wrong one came from a plausible
story.

- **main was broken for hours while reporting SUCCESS.** Two tests needed two
  attempts each; retries hid it. The repo's own audit was already printing
  *"A green job is hiding these"* — nothing consumed it.
- The 96h census found this only by reading the logs of **green** jobs.
- `card-drop-patch.spec.ts` alone was **175 flaky observations, 25% of all
  flakiness**, one day old and accelerating, riding green on main.
- A vacuity sweep of the whole suite found **no vacuous test worth killing** —
  the obvious candidates (`toBeGreaterThanOrEqual(0)`) are instrument-reachability
  gates, because those probes return `-1` on failure.
- #1851's own test would have been **green and vacuous twice** — a frozen
  gradient scored 0.99 vs 1.01, decoded video 4.34 vs 4.55. Aliasing only exists
  above Nyquist, and neither subject had energy there. The fix was a better
  SUBJECT, not a better threshold.
- A positive control disproved my own Tab hypothesis before it shipped as a
  diagnosis.

**Ask of any gate: what is it structurally unable to see, and would a green run
look any different if the answer were "everything"?**
