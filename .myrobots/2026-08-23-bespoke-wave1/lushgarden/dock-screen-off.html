LUSH GARDEN — dock faceplate · STATE 2: SCREEN OFF

Spec and mockup only; nothing here is implemented. OFF unmounts the picture and reclaims its vertical space — the fleet standard. Nothing about the module stops.

state 1 · screen on state 2 · screen off
⚠ This state carries an obligation no other adopter has. Collapsing must not stop surface.draw. On every other module with a SCREEN switch the picture is stateless enough that “keeps rendering” is a performance nicety. Here the picture is a running integration — the garden at second 30 contains the garden at second 10 — so a collapse that paused it would produce a garden younger than the rack when the screen came back. Make it a permanent leg of the face model test: with SCREEN OFF for N frames, read('spawnCount') must be strictly higher than before, not equal.
⚠ And markWatched must still fire. The blit IS the watch mark, so an OFF state that merely stops blitting drops the node out of the pull set. On a filter that stalls a preview; on this module it would stop the GENERATOR every downstream node is sampling — lushgarden is a pure SOURCE with no input requirement, so it is the origin of the signal and a lapsed mark mutes the patch, not the preview.

determinism — the strongest story in the wave

halfmechanism
stop itfreezeFaceVideo writes params.freeze = 1, and surface.draw returns before anything else. It then verifies the canvases held, in the page, across real rAF frames — an assertion, not a hope.
choose WHICHsimPin on __lushgardenVrtSeed. It pins a fixed 24-plant set from a seeded RNG and suppresses all further spawning, so the surface is time-invariant rather than merely phase-pinned — strictly stronger than the outlines pin it copies. The value reuses the seed the CARD scene already pins, so the layout is one a human has reviewed.
⚠ reachabilitysimPin installs boot-time globals with addInitScript, so it only reaches a factory in the PAGE's global scope. acidwarp is unreachable because its renderLocus is 'worker'. lushgarden declares no renderLocus — grep returns zero hits — so it runs main-thread and the global is visible.
the negative controla different seed must produce a visibly different dock capture. A pin that changes nothing is indistinguishable from a pin that never ran.
⚠ not the routeFACES_WITHOUT_SCENES. Its bar is evidence that simPin AND freeze cannot reach the renderer; here both do. And freezeIsNotASeam is a field on that same exemption type, so it is not applicable to a module in FACES.
