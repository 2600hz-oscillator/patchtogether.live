Spec and mockup only. The rename is a 14-character field, committed on Enter or blur and cancelled on Escape, that writes node.data.slots[slot].name in place inside one Yjs transaction. The clamp is the Electra's own name budget.

⚠ THE MUTATION RULE IS LOAD-BEARING AND HAS ALREADY BROKEN ONCE. “never rebuild-and-reassign data.slots … once integrated, spreading it into a fresh object re-integrates already-integrated Y types and Yjs throws 'Type already integrated' (the same trap that broke the second send-to-surface)”. defects found, for routing

idone line
13.1zero documentation, and the type system makes it unfixable in place: no docs field on MetaModuleDef, no DESCRIPTIONS entry, one line in the contract lock. The module's whole spec is a source comment no gate reads.
13.2the VRT treatment contradicts itself in three files — two exemption comments say this module belongs with controlSurface, and it is not exempt and carries a live gating baseline. Recommendation: keep the baseline, fix the prose.
13.5data-testid collision. Knob keys the testid on paramId alone, so two slots on the same param collide with each other AND with the source module's own knob. The existing e2e already works around it without naming it — and it is the reason faces-parity's multiset gate may red on a filled board.
13.6the detail status string is computed on four paths and rendered on none — a failed flash discards its own reason, including a thrown error message. The fix is the accessible name, not a painted line.
13.8only the FIRST board ever reaches the hardware. maxInstances:1 looks like the guard, but the workflow PIN is excluded from the cap — so a user can hold two, and pinned-electraControl sorts first, meaning the canvas one the user is looking at is the one silently ignored. No signal, no test. Owner decision.
13.9a slot bound to a renamed PARAM on a still-present module is never pruned, renders empty, and the only way to clear a slot is to right-click the proxy — which an empty-looking cell does not have. Permanently invisible dead state.
13.11no probe shape exists for a hardware-egress action. This module, launchpadControl and controlSurface all have one, so it is a cohort blocker. The honest first step is a broker-side ledger recording delivered: false rather than dropping it.
13.12the 6×6 geometry is re-typed in the assignment writer, the one place a wrong index binds a control to the wrong pot.
⚠ Risk: HIGHEST in the wave, for a reason no other module has. This module is in the owner's rack on every load — it is a workflow pin, undeletable while pinned, and the front end of a hardware pipeline with two already-shipped-and-fixed bugs in its teardown path. A regression here is not cosmetic; it is the board is empty and the Electra will not flash. Do not auto-merge, whatever the green says.
