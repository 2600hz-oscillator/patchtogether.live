Spec and mockup only. This one cannot be built yet — MetaModuleDef has no face field, so the declaration does not typecheck. The design below is what the two-PR sequence in §12 unblocks. The module is the only one in the fleet whose subject is other modules: thirty-six named holes, each holding a POINTER, and the board is the preset the Electra One hardware gets flashed with.

zone map

zonewhat it is
the boarda fullViewBody. Not editorSurface — that slot is UNWIRED and adopting it would mean a ModuleShell render-site change inside a face PR for no behavioural gain. fullViewBody is wired, is already drawer-gated, and does the job.
the 36 cellsenumerated from (row, knob) and never from the data, so all 36 always render. That is what makes an EMPTY slot a visible place rather than an absence — and it is why the "hide the empties" toggle is refused.
each filled cella real <Knob> proxying a param of ANOTHER node. Every range, curve and default comes off the SOURCE ParamDef; the card re-types zero numbers — the best-behaved card in this wave on the one-source rule.
the stripea LIVE read of the source module's control colour, never copied onto the slot.
bank labelsTOP / MID / BOT — ⚠ four source comments say MIDDLE / BOTTOM. The shipped abbreviations are what the e2e asserts.
Send to Electrain the BODY, not a ShellActionCell. An action cell requires a probe, and this action's observable is a MIDI device received a SysEx preset — which no probe shape can see. A probe that cannot observe the effect is the sixstrum defect with a green tick.
bandsnone. Zero params, so pages: [] and the empty-band filter removes everything. On this one module "the body is the whole plate" is honest, because there is nothing to lose — which is exactly the case the slot's own warning is not about.

⚠ driftControlContextMenu.svelte — the assignment WRITER — hand-writes its own ELECTRA_ROWS, ELECTRA_KNOBS and electraSlot(), held together only by a comment. The Push renderer re-exports from the source correctly; the writer does not. That is the one place a wrong index silently binds a control to the wrong pot.

each proxy<Knob>'s own aria-valuetext carries the VALUE, so aria-label carries the COORDINATE: Punch — Row 1 knob 1, control set 1 pot 1 — a NAME for a position, which is permitted resting text and is the one fact the grid position only implies.
each empty cell⚠ change it from aria-hidden: Row 3 knob 4 — empty. An empty slot is a place, and a board where 30 of 36 places are unspeakable cannot be described. This is not keyboard a11y; it is the accessible NAME of a rendered element.

Send to ElectraSend this board to the Electra One — extended with the detail string that is currently computed on four paths and rendered on none. It goes here, not onto the plate.
⚠ The blocker the inventory records is the WRONG one. The migration inventory carries blockers: ['needs-note-entry-cell'] for this module. That blocker is defined as "a note/short-text entry face cell … no face representation", and its probe looks for typed entry mounted by ModuleShell — "the ONE renderer every face cell is painted by". The rename field in this design is not a cell: it is markup inside a module-owned fullViewBody that ModuleShell never paints. The blocker is real for vstInstrument and vstFx, whose typed field must be a ranked control. It is not real for a module whose entire surface is a body. A stale scoping claim goes quietly green forever — correct the entry.
