Six derived quantities, zero text nodes. StatusLed has no value prop and its caption is static by contract, so a caller cannot smuggle a measurement through lit ? 'NOTE C5' : 'NOTE'.

⚠ The lamp must not be wired to lastNote

MidiLaneCardState.lastNote is "Last note received on the lane (MIDI int) for the readout". If it is a latched last value, lit={lastNote !== null} latches ON after the first note and never goes dark — a lamp that says nothing. Bind it to the HELD-KEY STACK (midiOutBuddy's activeNote !== null). If the held stack is not on the card state, adding it to snapshotState() is one line and is part of the face PR.

The channel number needs sixteen exemptions, and keeping the number is correct

looksNumeric matches 1…16, so face-readout-source.test.ts's Leg 2 fires. Take the exemption; do not invent a word. The shipped precedents both chose the number over an invented name — cvBuddy/ppqn ("there is no name for the state that is not the integer") and timelorde/swingSource. Derive the sixteen entries from the exported roster constant, never type them: an entry added and forgotten reddens, an entry removed is caught by the anchor leg, and deriving makes both impossible.

Seven params where there were zero

The precursor migrates channels · priority · retrig · mode · ccA · ccB · noteGateNote from node.data to params, keeping only lastDeviceId in node.data (written through mutateNode). midiclock's face PR did exactly this to divisor, and stated the rule that partitions them: "the DIVISION is a param, so it can be automated, MIDI-learned, exposed on a group and undone like any other value; the DEVICE is not, because its roster lives behind the browser's own MIDI permission."

⚠ Two consequences to predict rather than discover: +10 contract-lock lines (7 params + 3 families; options and face are both unprojected), and a Push 2 card appears where there was none — params: [] gives zero encoder strips today, and seven turnable params give seven. Do not pin an override: seven against eight encoders is no competition for slots, so the FACE tier already derives the right answer and an override REPLACES.
