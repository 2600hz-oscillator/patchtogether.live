⚠ NO StatusLed — a decision, not an omission

videobox-sync.ts is exactly the seam that wants to paint SYNCED / DRIFTING / 2 PEERS. The positive form exists (StatusLed, gated by status-led-source.test.ts) and is deliberately not used.

A lamp must name a state a player can ACT on. Drift correction is automatic and silent; "in sync" is the resting state of a working module. loopback's lamp earns its place because START CAPTURE / STOP depend on the state it shows — lamp and buttons are one control. videobox has no such gesture.

And the one actionable multiplayer state — a peer loaded a file you do not have — is already an affordance: the re-link overlay, which occupies the picture, names the file and is itself the button that fixes it.
