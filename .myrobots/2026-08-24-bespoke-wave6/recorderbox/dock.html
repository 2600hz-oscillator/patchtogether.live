the two cells, each argued

quality → selector. The cell is literally "a dropdown over a NAMED roster that lives in node.data (not a param)" (shell-cells.ts:166) — which is node.data.quality exactly. HIGH/BALANCED/SMALL are option NAMES, the permitted resting-text role.

record → toggle, not action. node.data.recording is genuine latched state synced over the Y.Doc, so a remote peer can flip it. An action has no value and could not render "a rack-mate started this recording".

width is NOT earned — and parity is UPGRADED

The card's 200×150 preview is not rebuilt here. It does not need to be: domain: 'video' gives this node a live per-node lane thumb at 160×120 (module-shell-model.ts:250-252) blitted from the same output FBO the encoder reads.

So the preview goes from only while the card is mounted to always, in the rack. A player who never opens the dock has more preview than before — which is the only reason dropping it is a design choice rather than a parity loss.
